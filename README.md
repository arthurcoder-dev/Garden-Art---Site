## 📖 Sobre o projeto

O **Garden Art** é um site desenvolvido para apresentar uma marca de camisetas personalizadas, valorizando criatividade, autenticidade e estilo individual.

O site permite que os visitantes conheçam a marca, visualizem os produtos disponíveis e encontrem facilmente as formas de contato para solicitar uma camiseta.

---

## 🖥️ Páginas

O projeto possui as seguintes páginas:

### 🏠 Home

Página inicial com:

- Apresentação da Garden Art;
- Destaque para as camisetas personalizadas;
- Imagem dos modelos utilizando as camisetas;
- Botão para entrar em contato;
- Links para as principais páginas do site.

### ✨ Sobre Nós

Página apresentando:

- A proposta da Garden Art;
- A importância da criatividade e autenticidade;
- A missão da marca;
- Informações sobre o atendimento online.

### 👕 Produtos

Página com os produtos disponíveis:

- Camiseta Zoro One Piece;
- Camiseta Garden Club;
- Camiseta Memphis;
- Camiseta Fuck12;
- Camiseta Danger;
- Camiseta Sapo Samurai.

Cada produto possui um botão para solicitação.

### 📱 Contato

O site disponibiliza diferentes formas de contato:

- Instagram;
- WhatsApp;
- E-mail.
